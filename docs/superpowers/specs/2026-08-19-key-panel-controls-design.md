# Key 面板控件精简设计

## 目标

在不改变现有两列独立纵向流和「模型与映射 / Key 管理」同卡分页的前提下，精简账号池、模型映射和 Key 管理的操作控件，并把 Key 的模型白名单改成可直接点击的按钮组。

## 图标操作

- 账号池删除和模型映射删除改为线框垃圾桶图标。
- Key 管理的复制、编辑、启用或停用、删除依次使用复制、铅笔、电源、垃圾桶图标。
- 图标使用内联 SVG，不引入第三方依赖。
- 按钮没有可见文字，但必须保留准确的 `title` 和 `aria-label`。
- 删除继续使用现有页内确认框。
- 图标按钮沿用现有颜色、悬停和键盘焦点风格，删除按钮保留危险色。

## 账号状态

账号池「状态」列只显示单个状态圆点，不再显示「存活」「额度用完」等可见文字。

- 正常为绿色。
- 受限、额度用完、IP 上限等为琥珀色。
- Token 失效和封禁为红色。
- 未探测或未知为灰色。
- 圆点通过 `title` 显示「状态：<详细状态>」，并用 `aria-label` 提供同样的可访问名称。

## 模型白名单按钮组

原生 `<select multiple>` 改为可换行的 `<button type="button" aria-pressed>` 按钮组：

- 首项为「不限」，新建 Key 时默认选中。
- 点击具体模型可独立选择或取消，支持多选。
- 选择任意具体模型后自动取消「不限」。
- 点击「不限」会清空全部具体模型。
- 取消最后一个具体模型时自动恢复「不限」。
- 编辑时按现有白名单回显。
- 当前模型目录中不存在但已被白名单引用的模型仍显示，避免保存时丢失。
- 后端契约不变：不限提交 `models: []`，限制模型提交模型 ID 数组。

## 表单反馈

- 默认主按钮文案改为「新建 Key」。
- 编辑时仍显示「保存修改」和「取消编辑」。
- `keyMsg` 从独立下一行移入按钮操作区右侧，保留 `aria-live="polite"`。
- 操作区空间不足时允许自然换行。
- 新建成功并复制时显示「已发出『名称』，文本 Key 已复制到剪贴板」。
- 复制失败时显示「已发出『名称』，点该 Key 行的复制图标获取完整 Key」。
- 编辑成功显示「已保存，立即生效（无需重启）」。
- 创建或保存失败时保留表单内容。

## 变更边界

修改：

- `web/index.html`
- `web/app.js`
- `web/style.css`
- `test/web-layout.test.mjs`

不修改 Key API、持久化格式、并发限制、每日上限、工作区布局和卡片分页结构。

## 验证与预览

先补布局契约测试并确认旧实现失败，再做最小前端实现。完成后运行全部离线测试、JS 语法检查和 `git diff --check`。本地验证通过后，把三个前端文件从本地标准输入原子覆盖到远端容器 `/app/web/`；不修改宿主机、不重启容器。用户刷新页面检查视觉效果，容器重建会回滚热改，正式持久化需后续提交并推送构建。
